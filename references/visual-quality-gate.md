# LW 视觉与可用性质量门禁

## 两个顶层指标

1. **视觉质量**：美观、有辨识度、内容表达准确；非单纯“炫技”。审片目标建议不低于85/100，且无严重字幕遮挡、抖动、黑帧、失真等硬伤。
2. **可用性/省手**：正常用户只提供选题、必要原片和最终反馈；分镜、配音、字幕、动画、音效、渲染、检测由 Skill 自动串联。必须逐项报告**真正自动完成**的比率；需要手动介入不能伪装。

## 风格系统

工作台的黑灰白和暖橙色是 UI 品牌，不应限制**成片**的视觉方案。可选 Swiss（排版秩序、几何网格与留白）、Future（层次、材质、精确的3D运镜和光影）、Archive（纸张/档案视觉、有节制的复古质感），但同一整片只使用一个主视觉系统；跨章节有理由时才切换，统一字体层级、间距、质感和字幕设计。

## 每个镜头的五条审查问题

- **信息职责**：画面是在说明、证明、对比、演示、承接还是总结？只放一句大字不能称为复杂内容可视化。
- **视觉焦点**：观众一眼应看哪里？背景、粒子、装饰不得抢夺主体和字幕的注意力。
- **运动动机**：为何要推、拉、旋、移？缓动、轨迹、物体惯性是否连续？无理由震动、抖动、旋转不通过。
- **阅读时间**：标题、信息卡、动态图表和字幕是否给出足够停留；片段结尾是否被下一转场提前盖住？
- **转场交接**：首尾几帧的构图/相机/光影/音乐是否可接；不得用闪白遮掩剪辑不连续。

## 实操验收建议

- 在真实目标画幅和分辨率下检查中英文文字、段落密度、字幕安全区（尤其9:16手机 UI 遮挡）、不同亮度设备的对比度。
- 全片不靠高频快切掩饰素材单薄；避免重复五个组件的固定样片。视觉组件应随内容换文本、关系、数据、时机和版式。
- 动画画面质量检查必须包含首帧、中间态、运动末帧及转场接缝；对 3D 镜头还需检查运动中的遮挡、景深突变、材质闪烁、空间尺度。
- 口播和音效都要看真实波形/时间码。字幕时间与实际音轨对齐；配乐不得压过讲解。大音量、高真峰值、削波等需要明确修复。
- QA 分为 **technical-pass**（编码/时码/解码/无黑帧等）与 **visual-pass**（审美/内容/节奏/字幕可读等）；两者都通过才可标记“ready-for-user-review”。

## 建议评分（满分100）

| 维度 | 权重 |
| --- | ---: |
| 视觉结构、品牌辨识度与审美 | 25 |
| 运镜、转场、缓动与动画质量 | 20 |
| 叙事与口播画面贴合度 | 20 |
| 字幕、信息图表及可读性 | 15 |
| 配音、BGM、音效与节奏 | 10 |
| 完整成片质量与技术稳定性 | 10 |

分数需来自实际视频与可定位反馈，不能用静态图、源码数量或自动化测试百分比冒充审片。存在无声、错字、音画漂移、黑帧、大面积遮挡或无授权素材时，即使加权得分较高也不放行。
