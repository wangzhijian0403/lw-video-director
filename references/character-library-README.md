## 文件（assets/，每个角色）

- `*-transparent.png` — 透明底静态图，直接叠在视频画面上用（剪映/CapCut/Remotion 都行）
- `*-greenscreen.jpg` — 绿幕底静态图，做新动画的底图
- `*-idle.mp4` — 绿幕待机动画，10 秒，24fps，循环用
  - codex / deepseek / doubao / claude：960×960
  - fish：1152×768
- `*-wave / *-typing / *-curtsy / *-share / *-dance.mp4` — 专属动作动画（上表），绿幕 10 秒
- 原图在上一级目录（`media-generation-*-video-style-0-*.webp`，白底 1600×1600，fish 是 1920×1280）

## 用法

- 绿幕视频进剪映：蒙版抠像 → 色度抠像，吸纯绿（0,255,0），强度拉到绿干净、边缘不吃掉为止；再用 HSL 把残绿饱和度拉最低。原视频就是这套流程。
- 透明 PNG 直接当贴纸/角标用，不用抠。
- 角色脚下有一圈浅色地面影（原图自带），抠绿后会留下来当自然阴影；不要的话用透明 PNG 版。
