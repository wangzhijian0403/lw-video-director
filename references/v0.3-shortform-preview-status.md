# LW Video Director / ai-video-director · v0.3.0-preview.1

**2026-11-22 · 已经合并到 `main` 的工作流预览，非稳定 Release**

## 本次变更

- 新增通用时长制作模式：用户想做多长按需求与实际音频规划，不对任何片长设全局硬限；30秒、5–7镜仅为一次独立回归样片。见 [时长政策](video-duration-policy.md)。
- 调整 SKILL.md 对工程能力的陈述，使其反映真实的 Remotion ProjectVideo 多镜头工作流；严格区分技术渲染与视觉/版权/自动化验收。
- 新增 references/shortform-30s-production.md 和 templates/shortform-30s-brief.example.md，便于其他智能体直接接手。
- **没有改动渲染算法、组件源码、依赖锁定、版权目录或《造纸术》母版。**

## 验收后再升级稳定版

持续让每个通过真实验收的功能增量合入 main；不要等整个素材库全部完成。正式 Release 仍需证明跨题材可运行的完整视频、音画与授权及可复现性。30秒样片仅是一次测试案例，非时长要求。未审核 FredTalk 和私有角色资产不应混入正式发布。

## 执行者入口

1. 新项目优先使用当前 main 的已验证能力；若测试未合并的外部动效，明确检出对应集成分支，并标记其尚未发布。
2. 阅读根目录 SKILL.md → references/shortform-30s-production.md。
3. 参考 templates/shortform-30s-brief.example.md；用户有新题材则优先采用用户题材。
4. 在本地运行 npm ci、npm test、npm run lint:project，并按**用户所需时长**执行真实整片渲染；本样例可以选择30秒。
5. 交付 MP4 + 工程 + 音轨 + 字幕 + 素材来源 + QA；把待完成和已完成分开。
