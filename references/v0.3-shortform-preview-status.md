## 本次变更

- 新增“短视频优先”制作模式：新题材25–35秒、5–7镜、配音实测、内容驱动设计、音效、字幕和质量门禁。
- 调整 SKILL.md 对工程能力的陈述，使其反映真实的 Remotion ProjectVideo 多镜头工作流；严格区分技术渲染与视觉/版权/自动化验收。
- 新增 references/shortform-30s-production.md 和 templates/shortform-30s-brief.example.md，便于其他智能体直接接手。
- **没有改动渲染算法、组件源码、依赖锁定、版权目录或《造纸术》母版。**

## 验收后再升级稳定版

当且仅当全新题材30秒MP4实际通过视觉、音画、授权及复现检查，且该项目新增通用组件在第二套不同输入上可渲染，才建议提出 v0.3.0 正式升级。避免把造纸题材专用代码和 FredTalk 未审的批量条目一口气合并到 main。

## 执行者入口

1. 检出 feature/skill-v0.3-shortform-preview（不得直接依 main/v0.2）。
2. 阅读根目录 SKILL.md → references/shortform-30s-production.md。
3. 参考 templates/shortform-30s-brief.example.md；用户有新题材则优先采用用户题材。
4. 在本地运行 npm ci、npm test、npm run lint:project 和真实30秒渲染。
5. 交付 MP4 + 工程 + 音轨 + 字幕 + 素材来源 + QA；把待完成和已完成分开。
